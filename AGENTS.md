# Project instructions

- This is a Windows desktop companion application. Read README.md, docs/decisions.md and docs/asset-notices.md before changing its scope.
- Preserve original image/GIF/WebP character customization, per-character memory, encrypted credentials, renderer sandbox and narrow IPC.
- Do not bundle third-party character assets, Cubism Core or Live2D runtime without a documented publication license review.
- Never print or commit API keys, request headers, databases, user assets or personal test output. Use mock providers for ordinary testing.
- Run typecheck and relevant tests. Record desktop, fixture and real-provider evidence separately in docs/validation.md.
- Maintain local commits. Remote publication and external account changes require user authorization.
