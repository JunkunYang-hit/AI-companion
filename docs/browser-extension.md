# 浏览器资料连接

1. 先运行 `npm.cmd run build`。它会把 Readability 和本项目读取逻辑构建为 browser-extension/content.js。
2. 在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 开启开发者模式，加载已解压扩展，选择本项目 browser-extension 文件夹。
3. 桌面伙伴 → 伙伴设置 → 勾选“允许浏览器扩展连接” → 保存。复制显示的端口、本机配对码到扩展弹窗，点“保存配对”。模型 API Key 不需要、也不应填写在扩展里。
4. 打开你选择的 HTTPS 页面，选中文字后点“分享当前选区 / 页面”；没有选区时在 DOM 副本上提取文章正文。表单、输入框、Cookie 和令牌不收集。
5. 要在当前标签持续陪伴，先勾选该选项；浏览器将请求当前站点权限，而不是默认所有网页权限。每 5 秒更新当前片段/播放状态。刷新后需要重新手动开启；没有无条件全站后台抓取。
6. B 站读取 video 当前时间、暂停/播放、倍速，尝试 textTracks / 当前显示字幕。请在播放器里手动开启字幕。无法取得字幕时只提供标题和进度。分 P / SPA 路由变化后会清空上一个视频的片段。
7. 看完选定段落可以点击“这一节看完了”，将你明确提供的结束信号交给学习模式。页面文字不能自己开启学习、提高预算或读取 Key。
8. 停止时点“停止分享并清除配对”，并可在桌面侧“撤销并清除资料缓存”。桌面侧撤销立即清空缓存/配对码并取消请求。浏览器侧停止后快照最迟 20 秒失效。重新启动桌面程序需要重新配对。

当前只限 Chromium 扩展，禁止隐身模式。不控制播放器、不下载视频、不自动转录。字幕 DOM / textTracks 的站点兼容性仍须按真实视频、分 P、倍速、后台、无字幕场景验收，不能把测试网页当真实站点验证。
