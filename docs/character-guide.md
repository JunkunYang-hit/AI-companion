# 角色与动作

当前版本内置原创小栖、桃桃。每个角色分别保存聊天、人格、问候语和记忆。

## 添加与切换

在“伙伴设置”点击“角色管理”：可切换、编辑、删除，或添加新角色。

- 图片/动图：填写角色名字，选择PNG、GIF或WebP，再编辑人格和问候语。
- 角色包：导入含character.json清单及图片动作的ZIP，创建独立角色。
- 点击问候语每行一条，最多20条，每条120字符，不调用模型。
- 删除角色会确认，并删除该角色的记录与用户导入素材；至少保留一个角色。

图片最多8 MB、4096×4096。素材用于本地外观，不自动发送给聊天模型。当前版本不支持Live2D模型。

## 导入动作

角色管理中的“动作管理”提供待机、走动、点击回应、安静休息、学习陪伴。选择动作后导入一个GIF/动态WebP，或一组按文件名排序的PNG帧，最多60帧、总量80 MB。PNG帧间隔50–2000毫秒，动图使用自身帧率；可在桌面预览。

## 桌面表现

在伙伴设置调整大小、拖动和气泡字号；气泡完整分段、自动淡出，不提供滚动历史。查看完整聊天请打开“聊一聊”。隐藏后点击桌面头像恢复，双击通知区图标打开主界面。

角色包清单格式见[示例说明](../src/shared/types.ts)中的CharacterPackage，资产仅接受图片，不接受脚本或可执行文件。
